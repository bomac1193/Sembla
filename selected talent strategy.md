# Selected Talent Strategy

Date: 2026-03-06

## Core Positioning

Sembla's moat should not be `runway models` in the traditional sense.
It should not be generic `AI talent` either.

The strongest position is:

`selected talent with image value, cultural relevance, and rights-cleared digital use`

## What The Talent Moat Should Be

The real edge sits in:

- editorial and culturally relevant talent
- represented digital rights
- explicit consent for digital replica use
- governed commercial reuse
- strong approval and restriction logic per face

This is stronger than:

- a commodity model board
- a generic creator roster
- a tech-led AI avatar directory

## What Sembla Should Look For

Best-fit talent:

- faces with strong editorial value
- culturally relevant multi-hyphenates
- DJs, producers, artists, performers, and image-led creatives
- models or supermodels who can carry brand value beyond one booking
- talent whose likeness can support repeat commercial use without becoming generic

The roster should feel:

- selective
- represented
- culturally literate
- commercially valuable

Not:

- mass-market
- volume-led
- generic fashion inventory

## Runway vs Editorial

`Runway` alone is not the moat.

Runway can still matter privately for credibility, but the public offer should lean more toward:

- editorial image value
- campaign value
- ambassador value
- cross-category cultural relevance

Why:

- runway prestige is useful, but it is not enough on its own
- the more defensible opportunity is in likeness rights and governed reuse
- brands are buying campaign utility, not only catwalk credentials

## Should Height And Dimensions Be Public?

Usually no.

Publicly listing height and measurements would push Sembla closer to a standard model board.
That weakens the newer, more strategic position.

## Best Public Profile Fields

Keep public profiles to:

- name
- image
- discipline / profile line
- location
- license or reference ID

## Keep Private Or On Request

Share privately when needed:

- height
- measurements
- fit notes
- walk / runway notes
- detailed restrictions
- passport data
- approval logic

This keeps the public roster premium while preserving practical casting utility.

## What Not To Lean Into

Do not make the moat:

- obvious `AI-ness`
- futuristic avatar aesthetics
- technical generation language
- synthetic novelty for its own sake

That would make the roster feel more like a tool demo than represented talent.

## What To Lean Into

Lean into:

- control
- scarcity
- representation
- consent
- governed use
- cultural and editorial value

## Working Category Sentence

`Selected talent represented for governed digital use.`

## Practical Direction

If there is a tradeoff between:

- looking like a standard model board
- and looking like a selective, rights-cleared cultural roster

choose the second one.

That is where Sembla becomes harder to copy.
